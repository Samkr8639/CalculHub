What is a Percentage Calculator?

A percentage calculator is a versatile tool used to solve common mathematical percentage problems, such as finding a percentage of a number, finding out what percentage one number is of another, or calculating percentage change (increase/decrease).

How to Use This Calculator

  1. Select the type of calculation you want to perform (e.g., X% of Y).
  2. Enter the numerical values in the input fields.
  3. Click Calculate to see the exact result immediately.

Percentage Formulas

1. What is X% of Y? → (X / 100) × Y
2. X is what percent of Y? → (X / Y) × 100
3. Percentage increase from X to Y → ((Y - X) / X) × 100

How do I calculate a percentage discount?
